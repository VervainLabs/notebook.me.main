# Code of Conduct

## Our Pledge

We are committed to making participation in this project a harassment-free experience for everyone.

---

## Expected Behavior

* Be respectful
* Be constructive
* Help others learn

---

## Unacceptable Behavior

* Harassment or discrimination
* Toxic language
* Personal attacks

---

## Enforcement

Project maintainers have the right to remove or edit content that violates this Code of Conduct.
