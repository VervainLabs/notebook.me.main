# 📝 Notebook.me

A feature-rich, modern Notepad alternative built using Java — designed for productivity, customization, and a smooth writing experience.

---

## ✨ Features

* 🎨 Multiple Themes (Dark, Dracula, Ocean, etc.)
* 📝 Markdown Rendering
* 🔍 Find & Replace
* 🧠 Dyslexia-Friendly Mode
* 🎯 Typing Test Mode
* 📓 Diary Feature
* 🖌️ Drawing Support
* ⚡ Lightweight & Fast

---

## 🚀 Getting Started

### 🔧 Run from Source

```bash
javac -d out src/**/*.java
java -cp out NotebookMe
```

---

## 📦 Build

### Build JAR

```bat
build.bat
```

### Build Portable App

```bat
build-portable.bat
```

Portable app runs without installing Java.
